# Step 9 - Character Bible

Phase B. Locks a consistent visual description for every recurring
character in the new story, so image/video generation doesn't drift across
shots. If a character recurs across multiple videos, keep it in a master
character library and have new stories reference it directly instead of
regenerating the bible from scratch each time. See
[[projects/faceless-video-content/reverse-engineering-videos/index|the workflow overview]].

```
Using the production plan and visual analysis, create a Character Bible for every important character.

For each character, define:
- Character name
- Species/type
- Age
- Gender, if visually identifiable
- Body proportions
- Height/build
- Face/head shape
- Eyes
- Hair/fur
- Skin/fur color
- Distinctive physical features
- Clothing
- Shoes
- Accessories
- Important props
- Color palette
- Typical facial expressions
- Body language
- Emotional baseline
- Character behavior
- Relationship to other characters

Separate permanent character traits from scene-specific changes.

The Character Bible must be detailed enough to maintain consistent character appearance across every generated image or video.
```
