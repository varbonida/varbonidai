# Step 2 - Scene Construction Analysis

Phase A. Run against the same Gemini conversation as Step 1, with Step 1's
result available as context. Save the result as `02-scene-construction.md`.
See [[projects/faceless-video-content/reverse-engineering-videos/index|the workflow overview]].

```
Reverse engineer every scene as a screenwriter studying how this short drama was constructed.

For each scene, analyze:
- Timestamp
- Scene objective
- Who wants what?
- Who or what prevents them from getting it?
- Source of conflict
- Information revealed
- Information withheld
- Emotional starting point
- Emotional ending point
- Turning point
- Stakes
- Why the audience should care
- Why the scene ends where it does
- How the scene sets up the next scene

Then identify the primary function of each scene:
- Establishing information
- Tension
- Character reveal
- Mystery
- Escalation
- Emotional relief
- Twist
- Later payoff
- Resolution

Finally, answer:
What would be lost if each scene were removed?

Focus on understanding how each scene contributes to the overall story rather than merely describing what happens in it.
```
