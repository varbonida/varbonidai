# Step 7 - Original Story Adaptation

Phase B, first step. This is the only step that needs the reference video's
blueprint (`06-story-blueprint.md`) and nothing else from Phase A - it does
not touch the original video or Steps 1-5's analysis again. It's also where
every actual creative swap belongs: new characters, new setting, new
conflict, new events, new dialogue, new ending. If the original is a
20-year-old boy and the new story needs a 23-year-old girl, this is the
step where that happens - not earlier. The original character never needs
to appear in any file from Step 8 onward. See
[[projects/faceless-video-content/reverse-engineering-videos/index|the workflow overview]].

```
Using the reusable storytelling blueprint from Step 6, create an ORIGINAL STORY ADAPTATION.

Preserve the underlying storytelling mechanics and structural principles, but replace every specific creative element with something new.

Define:

CHARACTERS
- Original character
- New character
- Age
- Gender
- Appearance
- Personality
- Character role
- Character relationships

SETTING
- Original setting
- New setting

CONFLICT
- Original conflict
- New conflict

STORY EVENTS
- Original major event
- New equivalent event

DIALOGUE
- Do not copy the original dialogue.
- Define the purpose each line of dialogue serves, then write new dialogue that serves the same purpose for the new characters and setting.

ENDING
- Identify the structural function of the original ending.
- Create a different ending that fulfills the same narrative function.

Make the new story substantially original while preserving the useful high-level storytelling structure.
```
