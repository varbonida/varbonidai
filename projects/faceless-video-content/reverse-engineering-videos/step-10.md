# Step 10 - Environment / Location Bible

Phase B. Same purpose as the Character Bible, applied to every recurring
location, so a place doesn't visually drift between shots. See
[[projects/faceless-video-content/reverse-engineering-videos/index|the workflow overview]].

```
Create an Environment and Location Bible for every important location in the story.

For each location, define:
- Location name
- Overall visual description
- Architecture or natural environment
- Spatial layout
- Important objects
- Props
- Materials and textures
- Background elements
- Foreground elements
- Lighting
- Time of day
- Weather
- Color palette
- Atmosphere
- Depth and spatial relationships
- Recurring visual elements

Identify which elements must remain consistent between shots.

The goal is to maintain strong environment and spatial continuity across all AI-generated shots.
```
