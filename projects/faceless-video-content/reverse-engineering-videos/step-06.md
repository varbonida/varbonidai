# Step 6 - Reusable Story Blueprint

Phase A, final step. Continue the same Gemini conversation with Steps 1-5
available as context. Save the result as `06-story-blueprint.md` - this is
the file Phase B actually consumes; the other five are supporting evidence.
See [[projects/faceless-video-content/reverse-engineering-videos/index|the workflow overview]].

Extraction only, no rewriting into a new example. An earlier version of this
step also asked for "a completely original example using the same
structural principles" - deliberately removed, since that's a separate
creative-writing job and Step 7 already does it properly, with the actual
adaptation decisions recorded rather than buried in an example.

```
Using everything observed in the previous analyses, reconstruct the underlying storytelling blueprint.

Do NOT copy:
- The story
- Characters
- Dialogue
- Distinctive creative elements
- Specific events

Instead, extract the reusable storytelling structure.

Analyze:
- Hook formula
- Character setup formula
- Conflict formula
- Escalation pattern
- Emotional progression
- Scene progression
- Revelation or twist mechanism
- Climax structure
- Ending structure
- Pacing pattern

Then summarize the underlying storytelling formula in a concise, reusable format that can be applied when developing a new story.

The purpose is to understand the storytelling mechanics and structural principles behind the video, not to copy the story itself.
```
