# Kelly - Communications

One note per day, filename `YYYY-MM-DD - Descriptive Title.md`, title
describing what that day's communication was about. Replaced a single
accumulating file on 2026-09-01 at Kelly's own request - she wanted to be
able to find a specific conversation again without scrolling a long log.

this folder.

on the relevant project's `overview.md` or `decisions.md` - this folder is the
running record it came from, not the only place it lives.
