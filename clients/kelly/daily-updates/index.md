# Kelly - Daily Updates

One note per week, Wednesday through the following Tuesday. Plain English, no
jargon, no code terms - written for Kelly to read as-is, no redaction needed
before it goes into [[concepts/client-safe-copy|the client-safe copy]].

Within a week's note, one dated heading per day worked, same format as
before:

```
### YYYY-MM-DD

**What I did today**
- ...

**What I'll work on next**
- ...

**Blockers**
- ... (or "None" if there aren't any)
```

Add the day's entry to the current week's note; skip a day entirely if
nothing worth telling her happened. Start a new week's note the first time
something gets logged on or after a Wednesday.
