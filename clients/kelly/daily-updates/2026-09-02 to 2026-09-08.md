# Week of 2026-09-02 to 2026-09-08

### 2026-09-02

**What I did today**
- Updated the one remaining screen that still had the old colors - a small
  pop-up that shows on the lock screen and the always-visible status area
  while dictating. It now matches the rest of the app.
- Finished renaming everything inside the iOS app to Avelisse - the on-screen
  name, the microphone prompt, and every internal reference. A few very
  specific things were deliberately left as they were, each for a real
  reason: the required credit to the original developer (removing it would
  misattribute their work), a hidden setting that lets anyone who already
  installed an earlier version upgrade cleanly, and a technical marker inside
  the dictionary files that would break them if changed.
- Found and fixed a broken setup script left over from an earlier change -
  it was still trying to save files to a location that no longer exists.
- Reorganized how your notes and daily updates are set up in Obsidian - each
  is now its own note (one per conversation for notes, one per week for
  updates) instead of one long file you'd have to scroll through. This is
  the change you asked about.
- Updated the very last screen still on the old colors, and cleaned up two
  dead links left over from the original project (one that would have routed
  any support money to the original developer instead of you). The old color
  scheme is now completely gone from the app - the only thing still using it
  is the app icon, which needs an actual design decision, not just a code
  change.

**What I'll work on next**

  open the project in Apple's software.
- Resolve the sound-effect rights question and the remaining placeholders
  (pricing, contact info).
- Decide on a new app icon design, since the current one is the last thing
  still carrying the old colors.

### 2026-09-03

**What I did today**
- Built section 2, the two places to talk, nearly end to end. Both buttons
