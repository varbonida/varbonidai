# Prompt Library

Reusable, proven AI prompts and instructions. Not a transcript archive: every
page here holds a self-contained, copy-ready prompt inside a code fence, with a
short description of what it does above it.

A prompt is not a wiki page. It answers "how do I make an AI do X", not "what do
I know about X", so `prompts/` sits beside the wiki rather than inside it. See
`CLAUDE.md` for the rule.

## Coding

- [[prompts/audit-check|Audit Check]] - repo audit before commercial rebrand or
  distribution (license, dependencies, AI models, privacy, branding)
- [[prompts/portfolio-site-build|Portfolio Site Build]] - scaffold a Next.js +
  Tailwind portfolio from an existing `design.md`

## Design

- [[prompts/app-redesign|App Redesign]] - redesign a mobile app UI from

## Marketing

- [[prompts/pinterest-pin-package|Pinterest Pin Package]] - full pin package
  (title, description, alt text, visual brief, AI image prompt, hashtags)
  built on buyer keywords, from a product name and photo, with optional star
  rating / Amazon's Choice trust-signal badges
- [[prompts/tiktok-affiliate-storyboard|TikTok Affiliate Storyboard]] - one
  9:16 image containing the 4-panel storyboard (Hook/Product/Payoff/CTA),
  production script table, voiceover script, and caption/hashtags, from a
  product name and photo. Stage 1 of 2.
- [[prompts/tiktok-affiliate-video-generation|TikTok Affiliate Video Generation]]
  - turns that storyboard image into the actual 10-second video. Stage 2 of 2.
