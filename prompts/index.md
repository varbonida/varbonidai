# Prompt Library

Reusable, proven AI prompts and instructions. Not a transcript archive: every
page here holds a self-contained, copy-ready prompt inside a code fence, with a
short description of what it does above it.

A prompt is not a wiki page. It answers "how do I make an AI do X", not "what do
I know about X", so `prompts/` sits beside the wiki rather than inside it. See
`CLAUDE.md` for the rule.
